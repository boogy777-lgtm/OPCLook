# Паритет UI: EleSy OPC Test Client 2.1.0.139 (Delphi) vs. текущий Rust

Сравнение выполняется по декомпилированным артефактам `opcda_re/`
(файлы `dfm/*.dfm.txt`, `handlers.txt`, строки `utf16_strings.txt`).
Статусы: ✅ — реализовано и покрыто тестом, ⏳ — частично/запланировано,
⛔ — не реализовано (с причиной).

## Вкладки (Сигналы / Журнал / Скрипт)

Оригинал использует `TPageControl`-подобную структуру панелей
`pnScript` / `pnScriptLog` с разделителями. В Rust нижние вкладки
«Скрипт» и «Журнал работы» теперь **взаимоисключающие**: когда включены оба
флага — показывается вкладка-бар и выбранная панель; когда включён только один —
показывается только эта панель (без вкладки-бара). Клик по вкладке — выбор
представления, флаги `show_script`/`show_log` по-прежнему управляют наличием панели.

| Функция | Статус |
|---|---|
| Переключение Скрипт / Журнал (взаимоисключающие вкладки) | ✅ (добавлено) |
| Один включённый флаг → одна панель без вкладок | ✅ (добавлено) |
| Подсказки вкладок «Журнал работы»/«Скрипт» | ✅ (добавлено) |
| Редактор скрипта | ✅ (текст, сохранение) |
| Журнал (просмотр/очистка/сохранение/загрузка) | ✅ |
| Интерпретатор скриптов | ⛔ (не реализован) |

| Распознавание «localhost» при поиске (IPv4-first) | `ToSocketAddrs` с сортировкой IPv4 вперёд | ✅ (добавлено, live-тест) |

## Примечания к реализации (этот проход)

- **Перетаскивание ЗАГОЛОВКОВ таблицы для переноса колонок не реализовано.** Причина: заголовочные ячейки `egui_extras` заняты ресайзером колонок и контекстным меню «Влево/Вправо». Живой horizontal drag заголовка невозможен без перехвата движения мыши на уровне столбцов `TableBuilder` (который уже управляет границами/ширинами), а при перестановке под перетаскиваемым заголовком строки таблицы «дёргаются» на каждом кадре — это тот же класс оверлейных конфликтов, из-за которого ранее сняли панельное меню. Поэтому основным (и надёжным) механизмом переноса остаётся диалог «Настройка столбцов» с DnD-строками, клавиатурным фолбэком Alt/Ctrl+↑/↓ и кнопками «↑/↓»; ПКМ по заголовку предоставляет «Влево/Вправо».
- **Панельное меню области тегов привязано только к неконфликтующим поверхностям** — строке-счётчику «Сигналов: N | Выбрано: M» и пустому телу таблицы (когда строк нет). Правая часть пустого заголовка и область ниже последней строки при ЗАПОЛНЕННОЙ таблице панельное меню не открывают (сознательное решение: широкий тёмный фон с `container_context_menu` снова породил бы наложение с меню строк/заголовка — ровно то, что убрали ранее).
- **Язык по умолчанию — русский.** `Lang::default() = Ru`, `default_lang()` возвращает `"ru"`, `Settings::lang()` фолбэчит на `Ru` для пустого/неизвестного кода. Явно персистённый язык в `settings.json` (например `"en"`) не перезаписывается; если у пользователя уже сохранён `"en"`, он останется английским до ручного переключения.
- **Нет пресета UA-URL.** Свежие настройки имеют пустой `last_ua_url` (по требованию продукта); поиск UA начинается с пустых полей, комбинированный поиск использует `DEFAULT_UA_HOST: DEFAULT_UA_PORT` (127.0.0.1:4840) + localhost.
- **Единственный источник констант и строк.** Все магические числа вынесены в `src/constants.rs`; пользовательские строки — в `src/i18n.rs` (словарь `Tr`), включая эндонимы `Lang::endonym()`. Коды операций BFF — ASCII-константы `bff::model::op`. Защита `tests/no_hardcoded_ui_strings.rs` не даёт вернуться хардкоду Cyrillic в `ui.rs`/`app.rs`.
