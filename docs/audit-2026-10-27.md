## 0. Как проверялось

- Статический разбор всего `src/` (≈42 тыс. строк) и `tests/`.
- Целевая платформа `i686-pc-windows-msvc` в этой среде не собирается
  (нет Windows std, а `windows`-крейт не собирается под Linux). Поэтому
  изменённый код проверен отдельным стендом под Linux, который подключает
  **настоящие** файлы проекта через `#[path]`:
  - `src/ui/dialogs/ua_tree.rs` + `src/i18n.rs`: компиляция, unit-тесты,
    headless-тесты egui_kittest (клик, двойной клик, disabled-узлы, нет
    конфликтов id), рендер в PNG;
  - функции слияния из `src/app/search.rs`: компиляция + тесты;
  - `src/bff/ua/discovery.rs`: компиляция против `async-opcua 0.19` и живой
    `FindServers`/`GetEndpoints` против sample-сервера `async-opcua`.
- Полный `cargo test` под Windows не запускался — его прогонит CI
  (`.github/workflows/windows-x86.yml`) на PR.

`url | http://opcfoundation.org/UA/SecurityPolicy#Basic256Sha256 / SignAndEncrypt`
— по строке на каждую пару (URL, политика, режим), с полными URI политик.

Стало (`src/ui/dialogs/ua_tree.rs`):

```text
▼ OPC UA Sample Server                 адресов: 1 · вариантов безопасности: 11
   ▼ opc.tcp://127.0.0.1:48555/        клик: Авто (или единственный вариант)
```

- Уровни: сервер → URL → вариант безопасности; двойной клик по URL или
  варианту = выбор + «Подключиться» (тот же путь валидации, что у кнопки).
