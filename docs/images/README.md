# Изображения проекта

`main-window.png` — headless-рендер настоящего интерфейса OPCLook на Linux с
синтетическими данными. Подключение, сервер и значения в снимке созданы
тестовыми средствами; снимок не подтверждает подключение к OPC-серверу и не
является снимком Windows.

Для повторного создания снимка из корня репозитория нужен рабочий headless
wgpu-рендерер и установленные зависимости приложения:

```sh
cargo test --target x86_64-unknown-linux-gnu --features ui-snapshots \
  --test readme_screenshot -- --ignored --nocapture
```

Тест перезаписывает `docs/images/main-window.png`. Имя сервера и значения в
исходном сценарии являются примерами и не содержат адресов или учётных данных.
