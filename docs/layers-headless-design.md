# Слои и headless-клиент

Проектируемая зависимость: GUI → engine и метаданные backend; CLI → engine,
contract и locale; engine → backend и contract; backend → contract; locale →
contract. Контракт не зависит от UI, локали или реализации транспорта. GUI
может запрашивать метаданные платформы, но отправку команд сессии и планирование
выполняет engine. CLI использует те же операции engine.

Состояние и таймеры сессий принадлежат engine; внешние клиенты получают снимки
и вызывают явные операции. Нулевой request ID у незапрошенных событий не несёт
эпоху соединения: старые сообщения такого вида нельзя надёжно отличить от новых.
CLI DA использует системные маршруты; управление сетевыми интерфейсами через
привилегированный GUI helper в CLI не входит. Отключение CLI завершает операцию
с ошибкой, автоматический интерактивный диалог восстановления отсутствует.

Эта запись фиксирует целевую архитектуру; реализация и проверки выполняются в
ветке refакторинга. До завершения она не описывает существующий код.
