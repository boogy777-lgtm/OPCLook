## Решения

- Тегe-дерево, вкладки и строка сервера рисуются через `allocate_exact_size` + painter,
  accesskit-метка задаётся `widget_info`; текст в метках сохранён там, где тесты ищут по нему.
- Фон активной вкладки: `panel_fill` с подмешиванием 13% цвета сильного текста — работает
  в светлой и тёмной теме без новых цветов; акцент — `selection.stroke.color` (поток theme может
  сменить его на единый акцент без правок здесь).
- F5 при пустом дереве раньше не делал ничего (дереву не на что вешать фокус), поэтому кнопка
  с подписью «(F5)» без доработки обманывала бы; клавиша обрабатывается в пустом состоянии,
  если ею не владеет таблица/текстовое поле/диалог.

## Открытые риски

- Неактивная вкладка не показывает «×» без наведения, поэтому с клавиатуры/программы чтения её
  не закрыть кнопкой (остаётся контекстное меню «Удалить из списка»; клавиатурный цикл
  Ctrl+Tab/Ctrl+N не затронут).
- Иконки панели дерева маленькие (22 px); глиф «Дочерние» (родитель с двумя потомками) и
  «По имени» (I-beam) — на глаз читаемы, но их смысл стоит проверить на пользователе.
- Раскрытие в таблице (UI1, часть `table.rs`) — зона потока `table`; `paint_expander` пока
  помечен `#[allow(dead_code)]` в `paint.rs`, у дерева он теперь используется.
- Windows-сборка не проверялась (только Linux-стенд), код не содержит Windows-специфики.
- Во время работы диск общей машины заполнился до 100% (мой промах: один `cargo check`
  без `CARGO_TARGET_DIR` собрал деп-ы в `target/` внутри worktree, ~330 МБ; удалено).
